### Phase 2: Data Query Language (DQL)
Today I mastered how to retrieve and filter data from a database.

* **Filtering:** Using `WHERE` with `AND`, `OR`, and parentheses for complex logic.
* **Special Cases:** Handling `NULL` values using `IS NULL` vs `IS NOT NULL`.
* **Sorting:** Organizing data using `ORDER BY` (ASC/DESC).
* **Pagination:** Mastering `LIMIT` to fetch specific chunks of data.
* **Wildcards:** Using `LIKE` with `%` for pattern matching.
